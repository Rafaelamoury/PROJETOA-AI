# Decisões

- **Um repositório** com C# e JavaScript para qualquer programador ver o produto inteiro.
- **Regra de negócio na API** (.NET). Next e Expo só consomem REST.
- **SQLite no desenvolvimento** para subir sem instalar PostgreSQL. Produção pode trocar a connection string para PostgreSQL (Npgsql) sem mudar os controllers.
- **Caixa único** nesta versão (sem conta banco separada).
- **Plantas P/M/G** são pés/mudas no campo, não fruto colhido.
- **Valor da produção** é gerencial: latas × preço da lata − custos de extração. Não entra sozinho no caixa.
