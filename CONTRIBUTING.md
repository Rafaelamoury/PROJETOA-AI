# Como contribuir

- Feature nova: endpoint na API (`backend/src/Acai.Api`) primeiro, depois a tela em `apps/web` e, se fizer sentido no campo, em `apps/mobile`.
- Não calcular saldo do caixa só no frontend.
- Nomes de pastas e rotas em português de negócio (caixa, producao, plantas) para o time achar rápido.
- Dados de exemplo ficam em `DbInitializer.cs`. Não commitar `acai.db`.
